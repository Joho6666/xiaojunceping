# AgentScope 知识库说明

## 下载后有什么

仓库内包含可公开分发的知识库种子目录，覆盖：

- 具体大模型与多模态模型：文本、推理、代码、视觉、视频、图像生成和音频
- Agent 与 AI 开发工具：Coding Agent、Agent SDK、工作流编排、模型网关、观测工具
- Skill、MCP、Plugin、浏览器和 GitHub 能力
- GitHub 开源项目、产品参考、部署平台和工程规则

种子条目带有官方 / GitHub / Registry 来源、能力标签、适用场景、成本说明、许可证或限制以及快照时间。它们是可公开发布的参考快照，不等于实时市场清单。

## 数据分层

1. 仓库种子：随代码发布，首次运行自动导入。
2. 实时补充：评估时按项目画像搜索 GitHub 和官方来源，并进行 URL / 仓库核验。
3. 本机能力：扫描本机已安装的 Skill、MCP 配置和 CLI，只保存名称、摘要和能力标签。
4. 用户导入：JSON 导入的自定义条目默认进入待确认状态。

本机数据库位置为 `.agentscope/knowledge.sqlite`。该目录被 `.gitignore` 忽略，用户历史、连接信息、API Key、OAuth Token、Cookie、系统路径和 MCP 密钥不会进入 Git。

## 本机扫描与导入

在 `/settings/knowledge` 点击“扫描本机 Skill / MCP”，应用只读取允许的公开元数据；不会读取凭据文件。扫描结果经用户勾选并确认后才写入本地知识库。

用户也可以上传 JSON。导入格式应包含名称、类别、摘要、能力标签和可选的 `sourceUrl`。导入项不会立即成为高可信推荐，必须经过来源确认或同步验证。

## 更新策略

```bash
npm run knowledge:sync
```

同步遵循“可信来源自动发布、社区来源待确认、失败保留最近快照”的策略。建议在 Windows 任务计划程序中每天运行一次。每次评估会显示知识库快照时间、实时搜索时间、来源和降级状态。

## 发布原则

不要把 `.agentscope/`、`.env*`、数据库导出、历史报告、连接配置、日志或用户上传数据提交到公共仓库。若要扩充所有用户都能获得的基础知识，应新增或修改 `data/` 下的公开种子文件，并为每条记录补充真实来源与更新时间。
